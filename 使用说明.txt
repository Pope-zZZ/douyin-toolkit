【抖音 + 油管 文案提取器】使用说明
================================

一、怎么打开
  1. 找到文件夹里的「抖音文案提取器.exe」，双击它
  2. 会弹出一个黑色小窗口 —— 正常的，别关它
  3. 几秒后浏览器会自动打开一个网页
     （没自动打开的话，自己开浏览器，地址栏输入 localhost:8080）

二、抖音：第一次配置 API Key（只需要做一次）
  1. 浏览器打开 https://cloud.siliconflow.cn
  2. 注册 / 登录（手机号即可，有免费额度）
  3. 「控制台」→「API 密钥」→「新建 API 密钥」，复制 sk- 开头的密钥
  4. 回到工具网页，点右上角「点击配置 API」，粘贴密钥 → 保存

三、抖音：怎么用
  1. 抖音 App 点「分享」→「复制链接」
  2. 粘贴到输入框，可填「只提取前 __ 秒」（留空=完整）
  3. 点「提取文案」出文案；点「获取信息」看无水印下载链接
  4. 批量：多个链接每行一个，会自动出现「批量提取」按钮

四、油管：第一次配置（三样，做一次）
  点右上角「点击配置 API」打开设置，填：
  1. 代理地址：你的梯子地址，例如 http://127.0.0.1:10808
     （端口看你梯子软件实际用的，常见 7890 / 10808 / 10809）
  2. cookies.txt 路径：你的 YouTube 登录态文件
     - 在 Edge/Chrome 装扩展「Get cookies.txt LOCALLY」
     - 打开 YouTube（确保登录）→ 点扩展 → Export → 得到 cookies.txt
     - 把它的完整路径填进去，例如 C:/Users/你的名字/Desktop/cookies.txt
  3. API Key：可选。只有视频没有字幕、需要用语音识别时才需要
     （配置方法同「二」）

五、油管：怎么用
  1. 点顶部「油管」标签页
  2. 粘贴 YouTube 链接
  3. 选画质（最高 / 4K / 2K / 1080p / 720p / 480p / 仅音频）
  4. 「获取信息」看标题、画质、字幕
  5. 「提取文案」→ 优先用字幕（快、准、免费），没字幕才语音识别
  6. 「下载」→ 下载视频到本地
  注意：1080p 及以下下载为 mp4；4K/2K 因 YouTube 只提供 webm 格式，
  下载会是 mkv/webm（播放没问题，剪辑软件可能要先转码）。

六、用完怎么关
  关掉那个黑色小窗口（点右上角 ×）。

七、常见问题
  Q: 油管提示「需要配置代理和 cookies」？
  A: 按「四」配置，尤其确认代理端口填对了、cookies.txt 路径能打开。

  Q: 油管提取文案很慢？
  A: 视频没字幕时会走语音识别，慢是正常的；有字幕的视频秒出。

  Q: cookies 过期了？
  A: 重新用扩展导出一次，更新路径即可（YouTube 登录态一般能撑几个月）。

  Q: 第一次运行 Windows 弹「已保护你的电脑」？
  A: 点「更多信息」→「仍要运行」。没买微软签名，正常现象。
